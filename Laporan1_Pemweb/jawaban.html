Jawaban Laporan Teori

1. Konsep Tag HTML

Tag adalah instruksi khusus dalam sintaks HTML yang berfungsi memberikan perintah kepada browser mengenai struktur dan cara menampilkan konten. Secara umum tag memiliki sepasang penanda (pembuka dan penutup), namun terdapat jenis void elements seperti <img>, <br>, atau <hr> yang tidak memerlukan tag penutup.

2. Elemen pada HTML

Elemen adalah satu kesatuan utuh mencakup tag pembuka, atribut, konten, hingga tag penutup.

  • Tagname: Identitas jenis elemen (contoh: p, h1).
  • Attribute: Informasi tambahan untuk memodifikasi perilaku elemen (contoh: src, href).
  • Content: Isi teks atau data di antara tag yang akan dirender browser.

Elemen dapat ditumpuk (nested) membentuk struktur hirarki atau DOM (Document Object Model) untuk tata letak yang kompleks.

3. Mekanisme Anchor

Anchor (<a>) berfungsi sebagai tautan (hyperlink) antar halaman atau bagian tertentu. Harus menyertakan atribut href berisi URL tujuan, di mana teks atau gambar di dalamnya akan menjadi area yang dapat diklik pengguna.

4. Multimedia

Image: Gambar gagal dimuat biasanya karena jalur file (path) salah, format tidak didukung, atau koneksi tidak stabil. Teks yang menggantikan gambar adalah fungsi atribut alt saat gambar gagal dimuat.

Audio: Memasukkan audio non-lokal dilakukan dengan menyematkan URL lengkap pada atribut src.

Video: Atribut autoplay sering tidak berjalan karena kebijakan privasi browser. Agar berfungsi, tambahkan atribut muted berdampingan dengan autoplay.
